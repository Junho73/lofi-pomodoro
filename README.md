# Lofi Pomodoro Timer 🌅

감성적인 노을빛 배경(Vibe Coding)과 Apple Reminders 스타일의 심플한 할 일 목록이 결합된 뽀모도로 타이머 웹 애플리케이션입니다.

## ✨ 주요 기능
- 🍅 **뽀모도로 타이머**: 집중 시간(25분)과 휴식 시간(5분)의 자동 전환 및 진행 상태 표시.
- ⚙️ **사용자 맞춤 설정**: 유저가 직접 원하는 집중/휴식 시간을 설정할 수 있습니다.
- 🌅 **감성적인 UI (Vibe Coding)**: Glassmorphism 패널, 부드러운 애니메이션, 그리고 집중/휴식 모드에 따라 변하는 배경 컬러.
- ✅ **간편한 투두 리스트**: Apple Reminders 스타일의 직관적인 체크박스와 할 일 목록 기능.

## 🛠️ 기술 스택
- React (Vite, TypeScript)
- CSS (순수 CSS 및 CSS Variables 활용)
- lucide-react (아이콘)
- Cypress (E2E 테스트)

## 🧪 Cypress E2E 테스트 과정 및 방법

본 프로젝트는 핵심 기능인 '타이머의 흐름'과 '사용자 UI 인터랙션'을 검증하기 위해 Cypress를 통한 E2E 테스트를 작성하였습니다.

### 1. 테스트 핵심 전략: Time Mocking
타이머 로직을 테스트하기 위해 실제로 25분을 기다릴 수는 없으므로, Cypress의 `cy.clock()`과 `cy.tick()`을 적극 활용하였습니다.

- **`cy.clock()`**: 브라우저의 전역 Date, setTimeout, setInterval 등의 시간 관련 함수들을 제어할 수 있게 모킹합니다.
- **`cy.tick(ms)`**: 지정한 밀리초(ms)만큼 시간을 강제로 흐르게 만듭니다. 이를 통해 순식간에 타이머가 완료되는 상황을 테스트할 수 있습니다.

### 2. 주요 테스트 시나리오 (`cypress/e2e/timer.cy.ts`)

#### ⏱️ 시나리오 A: 기본 타이머 흐름 테스트
1. 타이머를 시작(Play) 버튼을 누릅니다.
2. `cy.tick(2000)`을 호출해 2초를 빠르게 보낸 후 타이머 UI가 "24:58"로 줄어들었는지 검증합니다.
3. 다시 `cy.tick(25 * 60 * 1000)`을 호출해 25분을 흐르게 만듭니다.
4. "Focus Session" 텍스트가 "Break Time"으로 변경되었고, 남은 시간이 "05:00"로 전환되었는지 검증합니다.

#### ⚙️ 시나리오 B: 사용자 커스텀 시간 설정 테스트
1. 설정 모달창을 엽니다 (`data-cy="settings-btn"`).
2. 집중 시간을 '1분', 휴식 시간을 '2분'으로 변경 후 저장합니다.
3. 타이머 UI가 즉시 "01:00"으로 업데이트되었는지 확인합니다.
4. 재생 버튼을 누르고 `cy.tick(60 * 1000)`으로 1분을 건너뜁니다.
5. 올바르게 "Break Time"으로 넘어가며 타이머가 "02:00"으로 세팅되었는지 확인합니다.

#### ✅ 시나리오 C: 투두 리스트 조작 테스트
1. 인풋 창에 새로운 할 일을 입력하고 엔터키를 누릅니다.
2. 리스트에 항목이 추가되었는지 `cy.contains()`로 검증합니다.
3. Apple 스타일의 원형 체크박스를 클릭하고 `.completed` CSS 클래스가 올바르게 적용되어 줄 긋기 처리가 되는지 검증합니다.

### 3. 테스트 실행 방법
프로젝트 루트 디렉토리에서 다음 명령어를 실행하여 테스트를 진행할 수 있습니다.

```bash
# 1. 개발 서버를 먼저 실행합니다 (별도의 터미널 창)
npm run dev

# 2. Cypress 테스트를 실행합니다 (다른 터미널 창)
# UI를 보면서 테스트하려면:
npx cypress open
# 터미널에서 헤드리스 모드로 실행하려면:
npx cypress run
```
