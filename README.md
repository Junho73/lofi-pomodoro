# Lofi Pomodoro Timer 🎧🕰️

감성적인 배경음악(Lofi)과 함께 뽀모도로 기법(25분 집중, 5분 휴식)을 적용한 타이머 앱입니다. 
Apple Reminders 느낌의 간단한 할 일(Todo) 관리 기능이 포함되어 있으며, 집중 모드와 휴식 모드에 따라 따뜻한 노을빛(Sunset)과 시원한 푸른빛(Cool Blue)으로 배경색이 부드럽게 전환됩니다.

## ✨ 주요 기능

- 🍅 **뽀모도로 타이머**: 기본 25분 집중, 5분 휴식 로직 제공.
- ⚙️ **사용자 맞춤 설정**: 설정 모달에서 원하는 집중/휴식 시간을 직접 입력하여 타이머 커스터마이징 가능.
- 🎨 **다이내믹 UI (Vibe Coding)**: Glassmorphism 디자인 요소와 부드러운 상태 전환 애니메이션.
- 📝 **할 일 관리(Todo)**: Apple Reminders 스타일의 심플한 할 일 추가/완료/삭제 기능.

## 🛠️ 기술 스택

- React (Vite, TypeScript)
- CSS (순수 CSS 및 CSS Variables 활용)
- lucide-react (아이콘)

## 🐛 Cypress 에러 캡쳐 및 디버깅 실습
의도적인 버그를 주입하여 Cypress의 에러 캡쳐 기능과 디버깅 과정을 실습했습니다.
- **의도된 에러**: 타이머 초기값을 99분으로 잘못 설정하여 UI 텍스트(25:00) 불일치 에러 발생 유도.
- **결과**: 테스트 실패 시 `cypress/screenshots` 폴더에 에러 발생 순간의 화면 캡쳐본 자동 저장됨 확인.
- **해결 과정**: Cypress 에러 로그를 통해 실패 지점을 파악하고 코드(`App.tsx`)를 정상으로 원복 완료.
